Show every reply in a Matrix thread. Example: remuda butler matrix thread '$EVENT_ID'

Usage: remuda butler matrix thread [OPTIONS] EVENT_ID

Arguments:
  <EVENT_ID>  Event that starts the thread, e.g. $abc123, or a Butler mail id (01M...)

Options:
  -h, --help         Print help
      --json         Print machine-readable JSON
      --room <ROOM>  Room ID, alias or name (default: the configured room)
  -n, --n <N>        History only: number of events (default: 20; range: 1..200)
  -o, --o <PATH>     Download only: absolute output path (default: $HOME/matrix-<media>)
