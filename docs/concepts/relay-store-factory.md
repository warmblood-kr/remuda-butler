# Frozen relay_store factory DI v1 (abstract)

packages/butler/relay_store_contract.lua exports M.open(opts)->store|nil,code. It validates providers and obtains/checks a root-owned owner capability, then returns named NOT_IMPLEMENTED authority methods. It does not open DB/write marker/register globals. QA binds this exact opts shape to real native fixtures NOW for behavioral RED. Product relay_store must later implement the same methods; abstract module is never a relay fallback.

opts.identity={root_id,account_id,device_id,relay_id}: stable nonsecret IDs, not credentials. account_id is canonical homeserver+Matrix-user identity; device_id fixes outbound transaction scope. relay_id identifies configured relay root. Inbox source key separately includes account/room/event/destination and excludes epoch/store_id/device changes. Account/device/root mismatch blocks reopening; config change is explicit migration.

Providers are functions called WITHOUT implicit self. Trusted root/service captures them outside replaceable matrix/relay globals. Same-user arbitrary Lua is not a security boundary. Caller manifest legacy_owners_quiescent=true/external_fence_verified=true flags MUST NOT authorize anything.

owner.acquire(identity)->opaque_cap|nil,code; check(cap,operation,identity)->true|nil,code; describe(cap)->{root_id,owner_id,epoch}; release(cap,disposition)->true|nil,code. acquire uses root strong owner registry + actual Butler-home process exclusion, verifies every old owner stopped/request+timer cleanup, and refuses unsupported/unknown legacy orphan. A file lock alone is not sameprocess exclusion. Provider retains capability strongly; mutable public token/lease time is not proof. check runs before prepare, every SQL mutation, cursor read used to poll, and immediately before POST. SQL additionally CASes store_id/owner_id/epoch. root must never grant takeover solely by expiry. Cap release does not implicitly stop external requests.

db.acquire({name='relay',max_bytes,timeout_ms,max_rows,migrations})->lease|nil,code. Capture mod-owned remuda.db.open;  lease={handle=native_db,ownership='owned'|'borrowed',release=function(disposition)}. Store owns lease. On close/error call release exactly once. owned closes underlying handle; borrowed does NOT close it, provider quarantines it on unknown_commit/rollback_failed and forbids reuse until reconciled. Borrowed connection must be EXCLUSIVE to store with no caller transaction/parallel use. Default production provider should own dedicated handle. Store never commits caller transaction. No network/marker/inbox callback inside DB transaction.

marker.read()->{status='missing'}|{status='present',raw=string<=4096}|nil,code. publish(raw)->true|nil,{code='io',outcome='not_applied'|'unknown'}. Only a provider with proven pre-rename failure may report not_applied; fs.write_atomic failure defaults UNKNOWN because Unix parent-sync can fail after rename. Never infer prior bytes still present. Re-read and reconcile marker+DB anchors after unknown; remain blocked/import-only, no automatic legacy fallback. Unix661 helper file+parent sync proven; other nodes/platforms must supply verified capability.

anchors.inspect()->{db_exists=bool,manifest_status='absent'|'present'|'unknown',store_id?,epoch?,export_footer?}|nil,code; metadata-only before DB/source; unknown/error failsclosed. It must not use create-capable db.open for existence/read-only proof. Missing marker+DB/manifest/footer evidence is not fresh; require reconcile. All anchors deleted cannot be detected; no automatic fresh decision. Manifest source stamps include primary/backup_evidence/acks/drain roles; backup stays retained evidence, never merged authority.

json.decode_record(raw,limits)->value|nil,code and encode_record(value,limits)->raw|nil,code ONLY bounded individual payloads. Never call source root decoder. Imported raw JSON token text is authoritative; decode/reencode cannot preserve arbitrary precision/unknown lexical tokens. SQL JSON1 validates/splits source. digest.sha256(bytes<=65536)->64 lowercasehex. No native hash API; existing guard_approval.sha256 source is reusable pureLua5.4 provider, must not load its whole runtime to import. 64KiB chunks hashed separately; root H("butler-relay-source-v1\0"..decimal_length.."\0"..concat(chunkhex)) (<=33KiB), avoiding one huge synchronous hash. Compare retained source bytes as well as digest; no count-only witness.

opts.faults=nil in product; QA function(boundary,context)->nil or {code,outcome}. Metadata only. Boundaries: before_commit; commit_reply_after_commit; active_marker_publish; open; rollback; before_post; post_reply_after_accept. Faults wrap REAL native DB/FS so commit-before-error truly commits. Providers own failure injection, never test booleans interpreted as authority. Mutators return result_table|nil,code; operation-conflict input equality compares full bounded canonical input, not only weak digest.
